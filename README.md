# Features

Live Market Dashboard
- Live NIFTY 50 & SENSEX prices
- Real-time stock prices
- Company fundamentals
- Market statistics
- Search and sector filters

 Stock Screener
- Filter companies by sector
- View valuation metrics
- Browse tracked companies

 Stock Comparison
Compare two companies side-by-side using:

- Current Price
- Market Cap
- P/E Ratio
- ROE
- Daily Change %
- Sector

 Portfolio Tracker
- Add stocks
- Remove stocks
- Track holdings
- View portfolio performance

Company Inspector
Detailed information including:

- Historical Price Chart
- Market Cap
- P/E Ratio
- ROE
- Sector
- Live Price
